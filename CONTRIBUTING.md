# Contributing

Thanks for helping improve Awesome Solana OSS. This list highlights open-source Solana repositories that are useful for learning, building, and contributing across the ecosystem.

## What to Add

- Public Solana repositories with a clear open-source license.
- Developer tooling, templates, protocol code, wallets, infrastructure, data tools, education resources, and maintained examples.
- Updates that fix stale links, maintenance status, team names, categories, or license information.

Avoid adding closed-source products, dead repositories, duplicate entries, or links without a clear Solana developer or contributor use case.

## Entry Guidelines

- Add new projects to the most specific existing section.
- Keep table formatting aligned with neighboring rows.
- Use the canonical repository link when possible.
- Mark maintenance status honestly based on recent activity and project context.
- Keep descriptions and team names short and factual.

## Pull Request Checklist

- Search the README for duplicates before adding a project.
- Confirm each new or changed link resolves.
- Confirm the listed project has an open-source license.
- Review the rendered Markdown table for broken columns.
- Explain whether the PR adds a project, updates metadata, fixes a link, or reorganizes an entry.

Small documentation fixes are welcome when they make the list easier to maintain.
