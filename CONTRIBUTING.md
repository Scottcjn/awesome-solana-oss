# Contributing to Awesome Solana (Open-Source Edition)

Thanks for helping map the Solana open-source ecosystem!

## Quick Start

1. Fork this repository
2. Add your project to the appropriate table
3. Open a Pull Request

## Adding a Project

### Table Format

```markdown
| Name | Team / Dev | Actively Maintained? | Link |
|------|------------|---------------------|------|
| Project Name | [Team](twitter/link) | Yes/No | [View](github-link) |
```

### Required Fields

- **Name**: Project name
- **Team / Dev**: Link to team or developer (Twitter or GitHub)
- **Maintained**: "Yes" or "No"
- **Link**: Direct GitHub link

## Categories

- **🏃 Good Starters** - Beginner-friendly projects
- **💻 Dev Tooling** - Development tools
- **🖼️ NFTs & Metaplex** - NFT ecosystem
- **💰 DeFi** - Decentralized finance
- **🎮 Gaming** - Game development
- **📱 Mobile** - Mobile projects
- **🔐 Security** - Security tools

## Quality Criteria

**Accepted:**
- ✅ Open source (valid license: MIT, GPL, Apache, etc.)
- ✅ Solana-specific or Solana-compatible
- ✅ Active or historically significant

**Not accepted:**
- ❌ Closed-source projects
- ❌ Unlicensed code
- ❌ Scam/malicious projects
- ❌ Non-Solana projects

## Pull Request Checklist

- [ ] Repository has valid open-source license
- [ ] Added to correct category table
- [ ] All fields filled correctly
- [ ] Link works and points to GitHub
- [ ] "Actively Maintained" status is accurate

## Updating Entries

You can also:
- Update maintenance status
- Add new categories
- Remove dead projects
- Fix broken links
