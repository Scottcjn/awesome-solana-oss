# Contributing to Awesome Solana OSS

Thank you for contributing to the Awesome Solana Open Source list!

## Adding Projects

1. Check README.md to avoid duplicates
2. Add to appropriate category
3. Format: `- [Project](link) - Description`

## Categories

- DeFi
- NFT/Media
- Gaming
- Infrastructure
- Tools & SDKs

## Guidelines

- Active open source projects only
- Working links
- Brief description

## PR Process

1. Fork
2. Add project
3. Submit PR
